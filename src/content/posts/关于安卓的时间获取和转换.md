### 一：根据`年月日`获取`时间戳`

常用的有两种方式，一种是用`Time`，一种是用`Calendar`，代码如下：

#### Time:

```java
Time time = new Time("GMT+8");
time.setToNow();
int year = time.year; // 年
int month = time.month; // 月
int day = time.monthDay; // 日
int timeStemp = time.toMillis(true); // 时间戳（忽略夏令时）
```

#### Calendar:

```java
        Calendar calendar = Calendar.getInstance();
        calendar.setTimeZone(TimeZone.getTimeZone("GMT+8")); // 设置时区无效
        calendar.getTimeInMillis();
        calendar.getTime().getYear();
        calendar.getTime().getMonth();
        calendar.getTime().getDay();
```

> 要注意的时，Calendar对象设置时区后，获得到的时间戳还是标准时间。
